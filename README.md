# Pizza Casa — сайт пиццерии

## Что внутри
- Адаптивный сайт на HTML, CSS и JavaScript.
- Каталог пиццы, фильтры и корзина.
- Форма заказа: имя, телефон, адрес, комментарий.
- Node.js/Express сервер, который отправляет заказ в Telegram.

## Запуск на компьютере
1. Установите Node.js (LTS): https://nodejs.org/
2. Распакуйте архив и откройте папку проекта в VS Code.
3. В терминале выполните `npm install`.
4. Скопируйте `.env.example` в файл `.env`.
5. Заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (инструкция ниже).
6. Выполните `npm start`.
7. Откройте http://localhost:3000

## Настройка Telegram
1. В Telegram найдите **@BotFather**, отправьте `/newbot` и пройдите создание бота.
2. Скопируйте токен, который выдаст BotFather, в `TELEGRAM_BOT_TOKEN`.
3. Откройте чат с созданным ботом и нажмите **Start** (или добавьте бота в нужную группу).
4. Чтобы получить chat ID, откройте в браузере:
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   Найдите в ответе `"chat":{"id":...}`. Это значение укажите в `TELEGRAM_CHAT_ID`.
   Для группы сначала добавьте бота в группу и отправьте туда сообщение.
5. Перезапустите сервер после изменения `.env`.

**Важно:** не публикуйте `.env`, токен бота и не вставляйте токен в `script.js` или HTML. Файл `.env` уже добавлен в `.gitignore`.

## Публикация
Это не статический сайт: для отправки заказов нужен сервер Node.js. Разместите проект на хостинге с поддержкой Node.js (например, Render, Railway или VPS), задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменных окружения хостинга и запустите `npm start`. Обычный GitHub Pages не сможет выполнить `server.js`.
